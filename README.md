## 🚀 About The Project

This project was completed as part of the **Tata IQ GenAI Data Analytics Internship**.

The project focuses on analyzing **customer delinquency data** to identify risk patterns, perform exploratory data analysis, generate business insights, and design a predictive analytics approach.

The objective was to transform raw data into meaningful insights that support:

- 📌 Business decision-making
- 📌 Risk assessment
- 📌 Customer behavior understanding
- 📌 Data-driven strategies

---

# 🎯 Business Problem

🏦 Financial organizations need better ways to identify customers who may have a higher probability of delinquency.

This project aims to answer:

❓ What patterns exist in customer delinquency?

❓ Which factors influence customer risk?

❓ How can analytics support better decisions?

❓ How can predictive models improve risk management?
